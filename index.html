Two lines

4 exhaustive
Parallel test via cross product. If not parallel, coplanarity check → intersecting vs skew. If parallel, coincident test via vector between points. Covers all of R³.

Line & plane

3 cases
n·d ≠ 0 → single point. n·d = 0 and P₀∈π → line lies in plane. Otherwise parallel no intersection.

Two planes

3 cases
Normals non-parallel → line of intersection. Normals parallel → check scalar D for coincident vs distinct.

Three planes

8 cases — Ontario table
General position point; pencil of planes sharing a line; triangular prism (pairwise lines, no common); two parallel cut by transversal (2 parallel lines); coincident pair+cutting line; coincident pair+parallel ∄; all coincident; all parallel distinct.
