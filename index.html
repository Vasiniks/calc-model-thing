Two lines

4 exhaustive cases
Direction vectors parallel or not. If not parallel: coplanar? intersecting vs skew. If parallel: coincident vs distinct. That covers all R³.

Line & plane

3 cases
n·d ≠ 0 → one point. n·d = 0 → point P₀ in plane? contained else parallel.

Two planes

3 cases
Normals parallel? no → line of intersection. yes → same plane? coincident else parallel distinct.

Three planes

8 cases — Ontario table
1: single point. 2: line (pencil). 3: triangular prism — pairwise lines, no common. 4: two parallel cut by third → 2 parallel lines. 5: coincident pair + cutting → line. 6: coincident pair + parallel third → ∅. 7: all coincident → plane. 8: all parallel distinct → ∅.
